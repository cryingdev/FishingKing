# 조작 상세

README의 요약 조작표를 자세히 풀어 쓴 문서입니다.


| 동작 | 방법 |
|---|---|
| 캐스팅 | 화면을 **아래로 당겼다가 던질 쪽으로 위로 튕기며 놓기** — 튕기는 속도 = 거리, 놓는 순간 튕긴 방향 = 방향 (천천히 제자리로 올려 놓으면 취소) |
| 얼음낚시 | 아래로 당긴 길이 = 얼음 구멍에 내릴 수심 |
| 챔질 | 찌가 **쑥 들어가면(!)** 탭. 톡톡 입질 중에 누르면 물고기가 도망감 |
| 루어 톡 | 루어가 물에 있을 때 화면을 **아래로 짧고 빠르게 당겼다 놓기**(0.35초 이내, 화면 높이 5% 이상) — 낚싯대를 톡 채어 올리는 느낌으로 루어가 움직임. 세게 당길수록 강하게. 위로 쓸어 올리는 건 톡이 아님(캐스팅 동작). 키보드 T(약) / Shift+T(강) |
| 릴 감기 | 화면 아무 곳에 **시계방향으로 원 그리기** (빠를수록 빨리 감김) |
| 줄 풀기 | **반시계방향** 원 — 장력이 빨간색일 때 줄이 끊어지지 않게 |
| 채비 회수 | `회수` 버튼 또는 원 그리기 |
| 낚싯대 스윕 | 채비가 물에 있을 때(대기·회수 중) 물 위를 **좌우로 곧게 밀기**(화면 폭 6% 이상, 수평에서 30° 이내) — 낚싯대 끝이 그쪽으로 기울고(최대 약 30°, 낚싯대 회전 한계 안에서) **손을 떼도 그대로**(반대로 밀면 돌아옴), 그대로 한 손가락으로 원을 그려 감으면 루어·채비가 그쪽으로 **휘어 들어옴**(감는 거리 × sin(각도) × 0.6만큼 옆으로) — 물고기·수초·전설어 은신처를 피하거나 지나가게. 찌는 감지 않아도 그쪽으로 천천히 조금 끌려감(한 번 밀 때 최대 1.5m, 줄 길이는 그대로, 물가 쪽으로는 물가 앞 0.4m에서 멈춤). 원·톡·탭과는 구분됨(원을 그리기 시작하면 기울임 취소). 얼음 구멍·전설어 조우 중에는 없음 |
| 사이드 프레셔 | 파이트 중 같은 동작(또는 A/D)으로 낚싯대를 기울임 — 물고기가 **실제로 옆으로 휩쓸며 달릴 때만** 셈(물고기가 도는 속도가 달리는 쪽으로 초당 0.2 rad를 넘으면 켜지고, 0.15 rad 아래로 0.1초 머물면 꺼짐; 달리는 반대쪽으로 버티는 동안은 꺾일 때까지 유지, 커버로 도망치거나 박혔을 땐 항상) — 똑바로 멀리 달리며 줄만 차고 나갈 땐 옆 방향이 없어 화살표도 사이드 효과(체력·꺾기·장력)도 없음(달리기 자체·줄 풀림·질주 길이는 그대로). 기울기가 끝까지의 20% 이하면 가운데(모델·파이트 바·화살표 모두 같은 값). 물고기가 **달리는 반대쪽**으로 기울이면 머리를 돌려 질주 방향을 꺾고(0.7초쯤 버티면 "방향을 꺾었다!" — 그쪽으로 돌아 달리다 남은 질주가 절반으로 짧아짐, 체력 소모 ×1.4, "사이드 프레셔!"), **같은 쪽**이면 더 멀리·오래 달림(체력 소모 ×0.8, "반대쪽으로!"). 장력은 **낚싯대와 줄 사이 각도**를 따름: 달리는 반대쪽으로 벌어질수록 최대 +10%(벌어진 각도만큼, 한껏 기울이면 30°에서 최대), 달리는 쪽(줄을 따라)으로 기울이면 최대 −3%. 여기에 물고기가 옆으로 휩쓸며 도는 실제 속도만큼(초당 0.45 rad에서 최대) 최대 +5% — 낚싯대가 가리키는 쪽에서 멀어지며 **낚싯대를 가로지르면** 전부, 낚싯대가 줄 방향이면 절반, 낚싯대가 이미 물고기가 가는 쪽을 가리키면 없음(드랙을 넘으면 그만큼 줄이 풀림). 각도는 아래 "보이는 기울기"로, 속도는 부드럽게 다듬어 셈. 쉴 때·점프 중·얼음에선 더해지지 않음. **보이는 기울기**: 체력·꺾기·장력 모두 화면의 낚싯대가 실제로 기울어 보이는 만큼만 셈 — 낚싯대는 정면에서 왼쪽 40°·오른쪽 30°까지만 돌아가므로(오른쪽은 낚싯대가 모자를 가로질러 더 좁음 — 40°로 넓히면 가까이 끌려온 물고기 쪽에서 모자에 겹침), 물고기가 그보다 바깥에 있으면 바깥쪽으로 더 기울여도 낚싯대가 한계에 걸려 그만큼은 없음(안쪽으로 기울이는 건 전부 셈), 기울이지 않으면 한계 밖 물고기라도 기울기 0·장력 그대로(한계에 걸린 낚싯대가 줄에서 벗어나 보이는 각도 — 오른쪽 끝 물고기면 최대 약 16° — 는 기울임으로 치지 않음). 파이트 바 가운데 칸: 물고기가 옆으로 휩쓸며 달리는 쪽 화살표(휩쓸 때만) + 낚싯대 기울기 막대(보이는 기울기 — 한계에 걸리면 막대도 그만큼만 기울어 보임; 가운데 20% 칸도 같은 값). 수면에 뜬 찌(찌 채비) 또는 물속으로 줄이 들어가는 지점(루어, 찌가 잠겼을 때) 바로 위에는 **밀어야 할 쪽을 가리키는 금색 화살표**(안 밀면 반짝이며 깜빡, 맞게 밀면 환하게 빛남, 반대로 밀면 흔들림; 옆으로 휩쓸지 않을 때·휴식·점프 중·얼음에선 숨김). 점프는 그대로, 전설어 파이트도 동일 |
| 장애물·던지기 | 물 위로 나온 바위·말뚝·보트·통나무·테트라포드·수정·나뭇가지에 채비가 맞으면 **튕겨 나감** — 바위 옆 2m 안에 떨어지면 `뱅크샷!`(자연스러운 착수: 8초간 근처 입질 ×1.3), 늘어진 가지 아래로 떨어지면 `가지 아래로 쏙!`. 바위 위·물가에 걸쳐지면 **톡** 당기거나 감아서 떨어뜨림(감아서 떨어뜨리면 가끔 걸림). 개구리 루어·포퍼는 **연잎 위에 앉음**(개구리: 감으면 연잎 위를 기어 오다 가장자리에서 `퐁` — 1.2초간 입질 기회 ×1.5, 가만히 두면 연잎을 뚫고 덮치기도), 다른 루어는 미끄러져 떨어지고(20% 연잎에 걸림), 찌 채비는 연잎에 걸림. 방파제·배 앞머리에 가려 안 보이는 발밑 물로 약하게 던지면 보이는 물까지 조금 더 날아가 떨어짐 |
| 밑걸림 풀기 | 물속 바위·가라앉은 통나무·수초에 바늘이 걸리면 `밑걸림!`(수초/갈대/연잎) — 파이트 바가 걸림 모드로 바뀌고 장력 = 걸림 장력. **톡** 당기거나(잠깐 감지 않고 줄을 느슨하게 둔 뒤면 더 잘 빠짐), 낚싯대를 **빠지는 쪽**(물고기처럼 줄의 반대 방향)으로 0.6초 밀어 두면 `빠졌다!`; 반대로 밀면 금색 화살표가 빠지는 쪽을 알려줌(수초·갈대·연잎은 어느 쪽이든 0.5초). **감으면** 장력이 올라 줄이 끊어짐 — 걸린 바늘 쪽에서 끊어지므로 루어는 잃고, 찌 채비는 찌가 남아 빈 바늘로 감겨 옴(아직 달려 있던 미끼 1개 소모, 빈 바늘이 다시 걸려 끊겨도 더 줄지 않음). 개구리 루어는 수초·연잎에 걸리지 않고, 소프트 웜은 거의 안 걸림. 얼음 구멍에선 밀기가 없어 톡(과 줄 늦추기)으로만 풂 |
| 끊기 | 밑걸림 중 `회수` 버튼이 `끊기`로 바뀜 — 누르면 줄을 끊음(억지로 감아 끊을 때와 같음: 루어 분실, 찌 채비는 찌가 남아 빈 바늘로 감겨 옴·미끼 1개 소모) |
| 커버로 도망 | 큰입배스·가물치·쏘가리·우럭 등은 파이트 중 바위·말뚝·보트·통나무·수초로 달아나 박힘(`커버로 파고든다!`) — 줄이 구조물에 쓸리면 파이트 바의 **쓸림** 게이지가 차고(차면 줄이 끊어짐, 쓸린 줄은 약해짐; 플로로카본은 강하고 PE 합사는 약함), **사이드 프레셔**(화살표 쪽으로 밀기)로 방향을 꺾으면 `커버에서 끌어냈다!`. 얼음 구멍에선 강꼬치고기·북극곤들매기·철갑상어가 얼음 밑으로 멀리 파고들 때만 줄이 구멍 가장자리에 쓸림(`얼음 밑으로 파고든다!` — 박혀 있을 때 꾸준히 감으면 끌어냄) |
| 키보드(PC) | Space/R 누르고 있기 = 감기, B = 풀기, T / Shift+T = 톡, A/D(←/→) = 준비 중엔 걷기 · 채비가 물에 있을 때/파이트 중엔 누르는 동안 낚싯대 좌우 (한쪽 용도로 누르고 있던 키는 떼었다 다시 눌러야 다른 용도로 동작) |

파이트 요령: 물고기가 **도망칠 때(질주/점프)** 는 감기를 멈추거나 풀어주고, **쉴 때·지쳤을 때** 힘껏 감습니다.
옆으로 휩쓸며 달리면(금색 화살표가 뜨면) 반대쪽으로 낚싯대를 밀어(사이드 프레셔) 방향을 꺾으세요. 똑바로 멀리 달릴 땐 밀 쪽이 없어요.
찌 채비는 파이트 중에도 **찌가 보입니다**: 찌는 바늘에서 찌 수심만큼 위 줄에 고정 — 줄이 물에 들어가는 지점에서 수면에 떠서
끌려가고(기울고, 옆으로 끌리면 물살 V자), 물고기가 깊이 들어가 줄이 팽팽하면 줄을 따라 **물속으로 끌려 들어갔다가**(어둡게·작게)
줄이 느슨해지거나 물고기가 올라오면 파문과 함께 **다시 떠오름**. 세게 당기면 잠깐 쑥 잠김, 점프 땐 줄을 따라 튐, 랜딩 땐 물고기 위 줄에
매달림(찌 수심이 더 길면 초릿대 끝). 사이드 프레셔 화살표는 떠 있는 찌 위에 뜸.

물고기가 빠지거나 줄이 끊기면: 물고기가 **바늘을 털고 빠지면** 채비는 줄에 그대로 남아 물고기 입에서 빠진 자리에서 감겨 옴(찌 채비는 찌가,
루어는 루어가 — 루어도 잃지 않음). 줄이 **끊기면 끊어진 자리**에 따라 다름: 장력으로 끊기면(가장 약한 바늘 매듭 쪽) 찌는 남아 감겨 오고,
구조물에 쓸려 끊긴 곳이 찌보다 아래(바늘 쪽)여도 찌가 남음. 줄이 다 풀려 끊기거나 찌보다 위(초릿대·줄이 물에 들어가는 지점과 찌 사이)에서
쓸려 끊기면 찌까지 통째로 잃음. 얼음 구멍도 같은 규칙: 구멍 가장자리에 쓸리는 곳은 줄이 구멍으로 들어가는 바로 아래라, 찌가 아직 구멍에
떠 있으면 그 아래에서 끊겨 찌가 구멍으로 올라오고, 멀리 파고든 물고기에 찌가 얼음 밑으로 끌려 들어가 있었으면 찌 위에서 끊겨 찌를 잃음.
루어는 어디서 끊기든 잃음(아끼는 루어도 — 떡밥으로 바뀜). 미끼는 챔질 때 한 번만 줄어듦(물고기가 먹었으니 줄이 끊겨도 더 줄지 않음;
전설어 조우로 건 황금 떡밥도 같음). 남은 찌 채비는 **빈 바늘**로 감겨 오고(다음 캐스팅 때 다시 미끼를 끼움), 이렇게 감겨 오는 동안엔
밑걸림도 입질도 없음. 입질에 챔질하지 못해 미끼만 떼먹히거나 연잎에 미끼가 뜯겨도 빈 바늘로 감겨 옴(빈 바늘엔 물고기가 안 덤빔).
줄이 끊어지면 끊어진 줄 끝이 초릿대 쪽으로 휙 말려 돌아가고(찌가 남으면 찌 아래 줄이 빈 바늘과 함께 튕겨 올라옴 — 그냥 빠질 땐 줄이
채비에 이어진 채로 느슨해질 뿐), 위쪽에 **잃어버린 채비** 알림이 아이템 아이콘과 함께 뜸(루어 이름, 미끼 ×개수, 찌) — 5,000코인 이상
루어는 금색에 값, 전설어 키 루어는 금색에 눈 표시. 잃은 게 없으면(물고기가 그냥 빠짐, 찌 채비가 바늘 쪽에서 끊김) 알림 없음.

장력 바의 흰 선은 릴 드랙(이 이상이면 줄이 미끄러져 풀림), 빨간 구간은 줄 강도 한계입니다.
